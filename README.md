# 🏠 HostelHub

HostelHub is a Flutter-based hostel management application designed to
digitize and simplify hostel-related activities for students and hostel
authorities.

## 📌 About the Project

Managing hostel activities through manual registers and separate
communication channels can be time-consuming and difficult to manage.

HostelHub provides a centralized digital platform for managing various
hostel activities through a single application. It includes functionality
for students as well as different hostel authorities.

The project was developed collaboratively as a group project.
